Welcome, network technician!

This course introduces Cisco IOS configuration and shows how Python can automate repeated network tasks using the Netmiko library.

Safety: This is a browser learning simulator. It does not connect to real routers or switches and does not run Python against network devices. Use Packet Tracer or an authorised lab for real configuration.

You will learn

  • Routers, switches, IOS command modes and CLI.
  • Basic switch configuration and management IP.
  • SSH and secure remote access.
  • Python variables, lists, loops and functions.
  • Netmiko connections, sending commands and verifying changes.
